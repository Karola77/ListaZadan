# Moja Lista Zadań

Pastelowa aplikacja webowa do zarządzania zadaniami.

## Opis projektu

Aplikacja umożliwia dodawanie, usuwanie oraz oznaczanie zadań jako wykonane.
Dane wyświetlane są w tabeli DataTables z możliwością wyszukiwania i sortowania.

Projekt został wykonany przy użyciu jQuery oraz Bootstrap.

---

## Funkcje aplikacji

- Dodawanie zadań
- Usuwanie zadań
- Oznaczanie jako zrobione
- Animacje (fadeIn, fadeOut, animate)
- Walidacja formularza (jQuery Validate)
- Tabela DataTables (sortowanie, wyszukiwanie, paginacja)
- Tryb ciemny / jasny
- Kolorowe oznaczenie priorytetu

---

## Wykorzystane technologie

- HTML5
- CSS3
- Bootstrap 5
- jQuery
- jQuery Validate
- DataTables
